## **Phase 1 — Python programming fundamentals**



Days 1–10

&#x20;Goal: Think logically and write basic programs independently.



| Day    | Topics to learn                                                   | Practical assignment                                             |
| ------ | ----------------------------------------------------------------- | ---------------------------------------------------------------- |
| **1**  | Python introduction, IDE, syntax, `print()`, `input()`, variables | Hello User + four-operation calculator                           |
| **2**  | Integers, floats, strings, Booleans, type conversion              | Age-to-days calculator and unit converter                        |
| **3**  | Strings, indexing, slicing, string methods, f-strings             | Username generator and text formatter                            |
| **4**  | Comparison operators, logical operators, `if`, `elif`, `else`     | Grade calculator, voting eligibility and even/odd checker        |
| **5**  | `for` loops, `range()`, nested loops                              | Multiplication tables, sum calculator and star patterns          |
| **6**  | `while`, `break`, `continue`, loop control                        | Number guessing game with limited attempts and replay            |
| **7**  | Lists, indexing, slicing, append, remove, sort                    | To-do list with add, delete, view and completion features        |
| **8**  | Tuples, sets, dictionaries, keys and values                       | Word frequency counter and simple phonebook                      |
| **9**  | Functions, parameters, arguments, return values, scope            | Convert calculator and to-do application into reusable functions |
| **10** | Revision and integration                                          | **Project 1: Student Report Card System**                        |

### **Day-by-day instructions**

**Day 1 — Start programming**

Learn:

- What is programming?
- How Python code executes.
- Variables and basic input/output.
- Basic arithmetic operators.

Assignments:

- Ask the user for their name and greet them.
- Ask for two numbers and calculate their sum.
- Build a calculator supporting addition, subtraction, multiplication and division.

Expected output: `main.py`, `exercises.py`, `notes.md`.

**Day 2 — Data types**

Learn:

- `int`, `float`, `str`, `bool`.
- `type()` and type conversion.
- User input validation basics.

Assignments:

- Calculate approximate days lived from age.
- Convert Celsius to Fahrenheit.
- Calculate simple interest.

**Day 3 — Strings**

Learn:

- Indexing and slicing.
- `.upper()`, `.lower()`, `.strip()`, `.replace()`.
- f-strings.

Assignments:

- Generate a username.
- Count characters in a sentence.
- Reverse a string.

**Day 4 — Conditions**

Learn:

- `if`, `elif`, `else`.
- Comparison and logical operators.
- Nested conditions.

Assignments:

- Student grade calculator.
- Voting eligibility checker.
- Even/odd and positive/negative checker.

**Day 5 — For loops**

Learn:

- Iteration.
- `range()`.
- Nested loops.

Assignments:

- Multiplication table.
- Sum of first N natural numbers.
- Star pattern generator.

**Day 6 — While loops**

Learn:

- `while`.
- `break` and `continue`.
- Loop termination.

Assignments:

- Number guessing game.
- Seven attempts maximum.
- Play-again functionality.

**Day 7 — Lists**

Learn:

- Creating and modifying lists.
- Indexing and slicing.
- List methods.

Assignments:

- To-do list.
- Add and remove tasks.
- Mark tasks complete.
- Sort tasks.

**Day 8 — Dictionaries and sets**

Learn:

- Key-value pairs.
- Dictionary operations.
- Sets and duplicate removal.
- Tuples.

Assignments:

- Word frequency counter.
- Contact dictionary.
- Remove duplicates from a list.

**Day 9 — Functions**

Learn:

- Defining functions.
- Parameters and arguments.
- Return values.
- Local and global scope.

Assignments:

- Convert your calculator into functions.
- Create a menu function.
- Create a main function.
- Separate program logic into reusable functions.

**Student Report Card Management System**

Required functionality:

- Add multiple students.
- Enter marks for different subjects.
- Calculate total marks and percentage.
- Assign grades.
- Determine pass/fail.
- Display individual student reports.
- Identify the class topper.

**Technical requirements:** Lists, dictionaries, functions, loops and conditions.

**Completion test:** Add at least five students and verify all calculations manually.
