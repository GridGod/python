### **Detailed assignments**

**Day 21 — Algorithm analysis**

Learn:

- What is an algorithm?
- Time complexity.
- Space complexity.
- Big-O notation.

Understand:

| Complexity | Meaning      |
| ---------- | ------------ |
| O(1)       | Constant     |
| O(log n)   | Logarithmic  |
| O(n)       | Linear       |
| O(n log n) | Linearithmic |
| O(n²)      | Quadratic    |

Assignment: Write three versions of a program that search through data and compare their complexity.

**Day 22 — Arrays and lists**

Learn:

- Traversal.
- Insertion.
- Deletion.
- Searching.
- Indexing.

Assignment:

- Reverse a list without `.reverse()`.
- Rotate a list by K positions.
- Solve LeetCode Two Sum.

**Day 23 — Strings**

Learn:

- String traversal.
- Character frequency.
- Palindromes.
- Anagrams.

Assignment:

- Create a palindrome checker.
- Create an anagram checker.
- Build a string analysis utility.

**Day 24 — Stacks**

Learn:

- LIFO.
- Push.
- Pop.
- Peek.

Assignment:

- Implement your own stack.
- Build a bracket matching checker.
- Solve LeetCode Valid Parentheses.

**Day 25 — Queues**

Learn:

- FIFO.
- Enqueue.
- Dequeue.
- Circular queue concept.

Assignment:

- Build a ticket counter simulator.
- Process customers in arrival order.

Use Python's `collections.deque` for an efficient queue implementation after understanding the underlying concept.

**Day 26 — Sorting**

Learn:

- Bubble sort.
- Selection sort.
- Comparison-based sorting.

Assignment:

- Implement both algorithms.
- Sort student marks.
- Compare them with Python's built-in `sorted()`.

**Day 27 — Searching**

Learn:

- Linear search.
- Binary search.
- Sorted versus unsorted data.

Assignment:

- Implement both algorithms.
- Search for a student by ID.
- Compare the number of comparisons.
